# Credit-Wise-Loan-System

## Project Overview

Credit Wise Loan System is a machine learning based project that predicts
whether a loan application is likely to be approved based on applicant
and financial attributes.


## Objective

The main objective is to build a machine learning model that can assist
in predicting loan approval decisions.

## Dataset

The dataset contains information about loan applicants such as:

- Gender
- Married
- Dependents
- Education
- Self Employment
- Applicant Income
- Coapplicant Income
- Loan Amount
- Loan Term
- Credit History
- Property Area


## Machine Learning Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Preprocessing
5. Feature Engineering
6. Train-Test Split
7. Model Training
8. Model Evaluation


## Algorithms Used

- Logistic Regression
- KNN
- Naive Bayes
  

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix
